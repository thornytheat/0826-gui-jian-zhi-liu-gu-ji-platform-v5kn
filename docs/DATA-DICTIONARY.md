# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 arrival, pickup, observation。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `parcel`、`entry`、`exit`、`observed`、`basis_points` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

以入柜为零点。观察日前未领取或观察日后领取都按观察日计算右删失。相同年龄先计算领取再移除删失，概率用精确分数联乘，按基点向下取整。时间超出最长可见样本时标记超出观察范围。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
